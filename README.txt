2026-10-25 左右別の速度・時間差
・通常は右腕／左腕それぞれの速度倍率（0.25〜3倍）とベジェ速度カーブを設定。
・「LINK（左右共通）」をONにすると共通の倍率・カーブを適用します。
  OFFにすると、保存してある左右別の設定へ戻ります。
・「左右の時間差」で遅らせる腕と0〜5秒を指定。速度変更後の実時間です。
  開始待ちでは先頭、終了待ちでは末尾の姿勢を保持します。
・これらの設定はMotionごとにブラウザへ自動保存します。
・比較画面の左は元データ1倍速、右は編集後。同じ経過秒数で比較し、
  最後の腕と元データが終了してからループします。再生中は視点を動かしません。
・位置グラフは元データ時刻、再生バーと負荷グラフは実際の経過時刻です。
・CSVは編集後の左右が両方終了するまで、同じ行数で30fps出力します。
  最後まで待つ腕には末尾の値を入れます。元データは変更しません。
・推定負荷は比較画面全体の同じ時間で集計。終了後の保持には重力分を含みます。

名前を付けて保存
「修正後を保存・書き出す」で名前を入力し「名前を付けて保存」。
速度・時間差・平滑化を反映した別の動きをリストへ追加し、Motion JSONを保存します。
リストはこのブラウザの保存領域（IndexedDB）に保持します。元の動きは残ります。
選び直す際は二重適用を避けるため1倍速・時間差なし・平滑化OFFで開きます。
ブラウザのサイトデータを消すとリストも消えるため、JSONファイルも保管してください。
別のブラウザや別のポートでは「ファイルを開く」でJSONを読み込めます。
