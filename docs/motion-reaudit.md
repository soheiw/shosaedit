# 作成済み動作の再点検結果

2026年10月25日。対象は作成済み17種類。元のMotion 1〜3は変更していません。

## 修正した問題

肘の局所CAD形状を比較すると、右肘を従来の正方向に曲げた場合、アルミとブラケットがモーターケースに入り込みました。上腕を回しても隣接部品間の干渉は解消しないため、影響する15種類を右肘は負方向、左肘は正方向の動きとして作り直しました。すでにこの方向で作られていた万歳2種類は維持しています。

肩すくめでは、手首の片軸だけを制限し、もう片軸を100度以上曲げていた問題も修正しました。手のひら法線だけでなく、手の長軸、手首の合成曲げ角、途中の回転の連続性を検査しています。

## 確認した範囲

全フレーム・両腕について、肘の曲げ方向、手首2軸と合成角、手全体のフレーム間回転、指固定、基準姿勢への戻り、整数形式を検査しました。左右のブラウザ設定は初期モデルの軸・基準角と一致しています。CAD画面では下表の途中・保持・戻りを確認し、肩すくめ・ガッツポーズ等は左右別の手の拡大でも照合しました。

## 残っている確認範囲

これは現モデル内での検査です。実機の可動域、モーターID・符号の実物照合、ケーブル、全動作を通じた腕全体の衝突は未検証です。肘のケース干渉の比較は、腕全体の無衝突を保証しません。手首40度という今回の生成上限も実機の許容限界ではありません。

ダブの伸ばす腕は、手首を無理に折らないため、手の表裏を鉛直上向きから約35度傾けています。弓引きでは手のひらの固定方向を指定せず、腕と手の配置を優先しています。これらを「全姿勢が完全に自然」とは扱っていません。

所作の味付けは、これらの姿勢条件と機械負荷とは別に、自然さ・美しさ・伝わる印象を比較します。[所作設計の研究メモ](shosa-research.md)を参照してください。
